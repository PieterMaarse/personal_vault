## Pitch

- Gesproken met Daan, Robbert en kort met Salmaan
- Wat is Cursor?
	- Cursor is an AI-powered code editor that understands your codebase and helps you code faster through natural language.
	- Het is een IDE (zoals RStudio of VScode ) die je download waarin je kunt programmeren
	- AI zit er in geïntegreerd
	- Overlegd met Andrei
	- Zou eventueel ook bij sommige SEO projecten nuttig kunnen zijn
	- Edge over concurrenten
- Hoe werkt Cursor?
	- Leest je hele codebase
		- Dus is veel beter
		- Begrijpt je code
	- Kan vragen stellen en zelf edits maken
	- Voorbeeld laten zien:
		- Chat
		- Agent
- Waar kan het ons bij helpen?
	- Bij programmeer opdrachten die niet in de microdata zijn
		- Het liefst zonder gevoelige data
		- Zoals de tool van Kim en Mika
	- Voorbeelden
		- CareerMap
		- Postcode loterij analyse
		- Tool poging
- Wat zijn de risico's?
	- Privacy
		- AI wordt gerund op externe server in Amerika (volgens Salmaan)
		- Stuurt je code (al dan niet encrypted) mee
		- Als je toestemming geeft tot de terminal kan hij eigenlijk alles
	- Fouten
- Hoe kunnen we het implementeren?
	- Pilot
		- Tijdsbesparing?
		- Hoeveel fouten maakt ie?
		- Begrijpen mensen hun eigen code nog?
		- Gaat het privacy-technisch goed
	- Vergelijkbaar met ChatGPT
		- Account vanuit SEO
		- AI-lunchseminar
- Wat moeten we uitzoeken
	- Enterprise plan
	- Privacy mogelijkheden
		- Wat kunnen we restricten op organisatie niveau
		- Opslaan data
		- Encryption (niet betrouwbaar?)
	- Beleid uitwerken
		- Wat mogen mensen wel/niet doen
		- Wat moet er in de .cursorignore
	- Salmaan had wat vragen gesteld

	- Zijn er projecten waar het nuttig bij is?
