## Korte samenvatting: Wat is Cursor?

Cursor is een zogeheten Integrated Development Environment (IDE), een omgeving waarin je kan programmeren (andere voorbeelden van IDEs zijn PyCharm of RStudio). Cursor ondersteunt meerdere talen, waaronder Python, R, HTML en STATA ==(checken!)==

In Cursor is AI ondersteuning geïntegreerd. Dit betekent dat hij direct je code kan lezen en aanpassingen kan maken, zonder dat je jouw code eerst hoeft te kopiëren naar een chat-based tool zoals ChatGPT.

Vrienden van mij die software developer zijn, bijvoorbeeld bij Uber, gebruiken dit veel en zeggen dat ze hierdoor heel veel productiever zijn. Ook heb ik Cursor gebruikt voor persoonlijke projecten en dit werkt een stuk beter en sneller dan ChatGPT.

Bij de AI lunchseminar werd gezegd dat we op zoek zijn naar manieren om onze concurrenten voor te blijven en ik ben er van overtuigd dat dit een kan zijn.

## De antwoorden op je vragen:

1. **Bij welk type projecten kan Cursor de meeste impact en tijdwinst behalen? (Overweeg mening van anderen)**
   Bij projecten waarbij geprogrammeerd wordt. Zowel voor data analyse als het bouwen van tools/websites is Cursor geschikt. Bij projecten in de microdata kan Cursor niet worden gebruikt.
   
2. **Hoe groot schat je de interesse en behoefte in onder developers binnen SEO?**
   ==Vragen aan mensen==
   Kim voor hun tool? Vragen wie er veel programmeren buiten de microdata. Voor veel projecten is het echter niet geschikt omdat het niet in de microdata omgeving gebruikt kan worden.
   
3. **Stel dat we hiermee zouden starten: hoe zou jij Cursor uitrollen binnen de organisatie?**
   Op een vergelijkbare manier als ChatGPT, dat je een account kan krijgen als je interesse hebt. Eventueel een AI lunchseminar om Cursor (en het bijbehorende beleid van SEO) te introduceren.
   
4. **Wat zijn in jouw optiek risico’s nadelen van Cursor?**
   Zoals met alle AI tools ligt het grootste risico bij het feit dat cursor data naar een externe server stuurt. Jij zei zelf dat de server van Cursor alleen in de VS ligt, waar OpenAI ook eentje in Europa heeft. 
   
   Het is mogelijk om Cursor met één prompt een gehele data analyse, website, of ML pipeline te laten programmeren. Dit kan er voor zorgen dat de gebruiker hun eigen code niet meer begrijpt, wat gevaarlijk is voor de betrouwbaarheid van ons werk. Gebruikers moeten kritisch blijven over de wat de AI schrijft. De verantwoordelijkheid hiervoor ligt bij de onderzoeker.
   
   - embeddings, indexing, wat gaat er naar de server? .gitignore?
   
5. **Waar liggen mogelijk (nieuwe) kansen bij het gebruik van Cursor? (Nieuwe dienstverlening, of ondersteuning aan bestaande diensten)**
   Gebruik van Cursor kan programmeer-intensieve opdrachten, zoals het bouwen van een website/tool of dataanalyse, enorm versnellen. Zelf heb ik bijvoorbeeld een website gemaakt met Cursor, terwijl ik eigenlijk helemaal geen websites kan maken.
   
   Een relevanter voorbeeld is wellicht de rekentool voor belastingen en toeslagen waar wat SEO'ers nu mee bezig zijn. Ik was benieuwd hoe goed cursor dit zou kunnen en in een half uur had ik een eerste versie af. Ik heb weinig vertrouwen in de berekening, maar voor de tijd dat ik er mee bezig ben geweest is het ongelooflijk goed.
   
6. **Welke alternatieven ken je en waarom heeft Cursor jouw voorkeur?**
   ChatGPT: voor programmeren veel onhandiger. Cursor leest je hele code en kan het automatisch aanpassen. Je hoeft dan niet meer te kopiëren en plakken naar chat en terug. Hetzelfde geldt voor andere chat-based tools.
   
   GitHub Copilot: Ik weet dat VScode een ondersteuning heeft voor GitHub Copilot. Dit is een vergelijkbare tool die ook de hele code kan lezen en zelf kan programmeren. Software developers (==op het internet/vrienden?==) zeggen echter dat Cursor beter werkt.
