## Setting

Doel regressie:
$$ P(RVU) = \alpha + \beta \ \mathbb{1}_{\{Q_{prof=1}\}} + \gamma ^\prime X_1 + \varepsilon$$

Geschatte regressie:
$$ P(RVU) = \alpha + \beta \ \hat{\mathbb{1}}_{\{Q_{prof=1}\}} + \gamma ^\prime X_1 + \varepsilon$$

Met prediction:
$$\mathbb{1}_{\{Q_{prof=1}\}} = \hat{\mathbb{1}}_{\{Q_{prof=1}\}} + \nu = \hat{f}(X_2) + \nu,$$

with $\hat{f}(X) \in \{0,1\}$ and $\nu \in \{-1, 0, 1\}$, for $f(\cdot)$ a classifier such as XGBoost or Random Fores, and potentially overlap in variables between $X_1$ and $X_2$.

$$\hat{\mathbb{1}}_{\{Q_{prof=1}\}} = \hat{f}(X_2) = \mathbb{1}_{\{Q_{prof=1}\}} - \nu,$$
Dus, we schatten 
$$ P(RVU) = \alpha + \beta \left[\mathbb{1}_{\{Q_{prof=1}\}} - \nu\right] + \gamma ^\prime X_1 + \varepsilon$$
Geeft 
$$ P(RVU) = \alpha + \beta \ \mathbb{1}_{\{Q_{prof=1}\}} + \gamma ^\prime X_1 + \varepsilon - \beta\nu$$
$$ P(RVU) = \alpha + \beta \ \mathbb{1}_{\{Q_{prof=1}\}} + \gamma ^\prime X_1 + \left(\varepsilon - \beta \left[\mathbb{1}_{\{Q_{prof=1}\}} - \hat{f(X_2)}\right]\right)$$

## Probleem

$\hat{\mathbb{1}}_{\{Q_{prof=1}\}}$ heeft een meetfout die zich uit als misclassified binary regressor. Dit leidt volgens [[Regression with a Misclassified Binary Regressor Correcting for the Hidden Bias]] op twee manieren tot bias:
1. Direct via attenuation-type bias
2. Via een hidden bias die zich uit via een dependence tussen de misclassification error en de covariates ($X$).

Voordeel: De misclassification error is the schatten door een validatie set te gebruiken. Echter moet dan misschien wel de aanname worden gedaan dat deze constant (independent) is voor de andere variabelen? Of niet via de manier van bovengenoemde paper?

Eigen problemen: 
- Als de schattingen van de binary regressor op dezelfde variabelen zijn geschat als de covariates, hoe werkt dit dan door naar de regressie?
- Verandert er nog iets omdat we ook een binaire target variable hebben? Geldt dit ook voor logistische regressie?
$$\mathbb{1}_{\{RVU\}} = f^{-1}\left( \alpha + \beta \ \hat{\mathbb{1}}_{\{Q_{prof=1}\}} + \gamma ^\prime X_1 + \varepsilon \right)$$
